개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-09-26

1. 수집하는 정보

Hermes Calendar는 앱 소유자 본인이 승인한 Google 계정의 캘린더, Gmail, 드라이브, 문서, 시트, 연락처 데이터에 Google API를 통해 접근합니다.

2. 이용 목적

접근한 데이터는 소유자 본인의 요청에 따라 일정 조회·등록, 메일 확인·작성, 문서 검색 등 개인 업무 보조에만 사용됩니다.

3. 저장 및 공유

인증 토큰과 데이터는 소유자 본인의 컴퓨터에만 저장되며, 제3자에게 판매·공유·전송하지 않습니다. 광고 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

Hermes Calendar의 Google API 데이터 사용 및 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회

https://myaccount.google.com/permissions 에서 언제든지 접근 권한을 철회할 수 있습니다.

English summary: Hermes Calendar accesses only the owner's own Google data, solely to assist the owner at their request. Tokens and data are stored only on the owner's computer and are never sold, shared or transferred to third parties or used for advertising. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at https://myaccount.google.com/permissions.
